# 语宙写作 OS

**从一个念头，到一部作品。**

语宙写作 OS 是基于 Obsidian 的一站式本地写作空间。它把构思、写作、资料整理、阅读学习和日常创作管理放进同一个仓库，让你围绕作品持续工作：用章节组织正文，用大纲检查故事，用人物与设定保持一致，再把阅读和生活中的发现带回创作。

适合长期写小说、短篇与系列作品，也适合希望建立自己的素材库和写作习惯的创作者。你可以先从一个项目、一章正文开始，按需要逐步使用其他工具。

## 一个围绕作品展开的工作空间

### 总看台与项目工作台

总看台集中呈现当前作品、最近项目、写作记录和常用入口；项目工作台汇集同一作品的正文、大纲、人物、世界观、时间线和研究资料。不同作品分别管理，共享的词典、锦囊与学习资料可以反复查用。

### 章节编排与沉浸式写作

用章节卡片记录标题、梗概、本章目标和外部冲突，按待写、初稿、修订、定稿查看进度。支持分卷、拖动编排与全书连读，便于检查故事顺序。

进入沉浸式写作后，可调整字体、字号、行距、纸张与聚焦范围。正文旁的资料栏可编辑本章信息，查阅其他章节、大纲、人物小传与档案、关系、世界观、伏笔、时间与研究；本章便签记录临时想法，浮动便签可固定在写作画面上。本地校对在正文自动标记命中的错词与规则问题，点击标记可查看建议；专注计时帮助记录写作节奏。

### 结构、大纲与伏笔

既可以连续撰写大纲，也可以借助三幕式、六阶段、英雄之旅等结构模板整理情节。结构中的讲解与案例帮助理解节点的作用，卡片墙和故事地图用于观察片段之间的关系。

写作时可从选中文字建立伏笔、推进或回收已有伏笔，并关联章节，让线索的出现与处理有据可查。

### 人物、关系、世界观与时间线

人物档案、小传和人物构建器支持不同深度的角色整理；写作资料栏按“人物小传 / 人物档案”分别呈现长篇文字与结构化资料，单独填写其中一类也可使用；人物关系帮助梳理角色之间的联系。世界观问卷用于推敲规则，设定资料用于保存地点、组织、道具等已确定内容；名称、别名与设定速查方便在正文中查阅。

故事时间线以事件资料为基础，可在年鉴、按人物视图及时间线白板中查看，帮助核对事件先后与人物经历。创作白板也可用于自由构思和项目内的可视化整理。

## 让积累回到写作

### 资源馆与写作学习

资源馆收纳写作词典、写作锦囊、小课堂与模板。查一个词、读一条方法、留下自己的备注，或把有用的发现存成灵感，再回到当前作品练习。完整仓库包随附预置学习资源，个人作品、习惯与影音条目从空状态开始。

### 本地书架与阅读笔记

导入自己有权使用的 EPUB，在阅读器中查看目录、搜索正文、添加书签、划线和批注。摘录可以回到原文定位，也可以整理为素材、灵感或导出的摘录文档。阅读记录便于回看自己的阅读进展。

伴读与拆书辅助属于可选 AI 功能，需要另行配置第三方服务；本地阅读、划线与笔记不需要接入 AI。

### 影音资料馆与外部资料整理

影音资料馆用于整理阅读、观看条目及自己的评价和观察。书籍区和影片区均可随时手动新建记录，填写标题、作者或导演、状态、简评、封面与关联项目。同步入口支持按界面指引连接或导入微信读书资料；豆瓣可读取个人公开电影列表，并选择“看过”“想看”“在看”的同步范围。

外部资料的可读取范围取决于来源平台、登录状态、隐私设置和访问限制。语宙不提供书籍或影视内容的下载授权。

### 灵感池与笔记本

随时收集还未成形的念头，在灵感池中回看、再次编辑或写成草稿；归档内容可在“已归档”中找回并恢复；需要连续记录的观察可放进笔记本。确定用于某部作品后，再整理进该项目的研究、人物、设定或章节。

## 支持持续创作的日常工具

- **今日书桌**：查看今日目标、待办、上次停笔位置与写作活动，快速回到正在写的内容。
- **任务中心**：管理计划日期、截止日期、优先级和关联项目，回看已完成事项。
- **习惯专注**：建立自己的习惯目标、打卡与专注计时，查看实际记录。
- **日记复盘**：记录日记、情绪觉察、每日／每周／每月复盘与梦境，把观察转成下一步行动。
- **完稿书架**：按完稿、投稿、发表与归档等阶段回看作品成果。
- **Notion 搬家**：入口显示“即将上线”，当前版本暂未开放导入。

## 怎样开始

1. 安装 Obsidian **1.9.10 或更高版本**。
2. 解压随产品提供的**完整仓库包**，在 Obsidian 中选择“打开本地仓库”，打开解压后的仓库文件夹。
3. 按包内说明启用语宙插件，使用自己的有效邮箱与激活码完成激活。
4. 从总看台新建项目，建立第一章，然后进入写作。人物、大纲与管理工具可按需要逐步补充。

完整包包含插件、仓库配置及预置资源。已有文稿库应继续在原库中使用插件更新入口；不要用新的空库覆盖自己的作品库。

## 文件、授权与联网

**作品保存在本地。** 正文与大部分资料以 Markdown 和属性保存在 Obsidian 仓库中，部分专用界面使用额外数据文件。保留完整仓库备份，才能同时保留正文、附件、设置与专用视图数据。本地写作和资料管理不依赖 AI 服务；本版本不提供云端文稿同步。

**AI 是可选服务。** 人物聊天、章节梗概、AI 校对、编辑意见、设定核对，以及伴读和拆书等功能需要接入模型。 语宙提供接入入口，第三方 AI 账号、API Key 与额度由用户自行开通，费用不包含在语宙授权中。效果取决于模型能力，速度与可用性取决于服务商。使用 AI 时，所选内容会发送给配置的服务商；不接入 AI，其他非 AI 功能仍可正常使用。设置中的“什么是 API？如何获取？”提供入门说明。不了解 API 的用户可在闲鱼咨询或购买相关接入服务，购买及使用问题请询问卖家；这些服务与语宙无关。

**公开下载与使用授权分开。** 此仓库公开分发正式程序更新与说明，使用产品仍需有效激活信息。它不是开源授权声明；具体使用及更新权益以购买时的授权说明为准。仓库不包含用户邮箱、激活记录、私人文稿或 API 密钥。随程序使用的第三方组件保留各自许可说明。

语宙是用于 Obsidian 的第三方产品，Obsidian 本体及其服务由 Obsidian 提供。第三方平台的账号、订阅与服务费用均由相应平台管理。

## 如何更新

当前正式版：[1.0.14](https://github.com/yuzhouosfw-web/yuzhou-writing-os-releases/releases/tag/1.0.14)。本版更新了沉浸式写作格式操作、资料与人物小传联动、灵感编辑与归档恢复、当天停笔记录，以及 AI 人物上下文读取。已有版本可直接升级，无需逐个安装中间版本。

在 **语宙设置 → 更新 → 检查更新 → 下载并安装** 中操作，安装完成后重启 Obsidian，使新版程序生效。更新只替换插件程序文件，保留原有文稿、项目资料、个人设置与激活信息。

[查看最新正式版本](https://github.com/yuzhouosfw-web/yuzhou-writing-os-releases/releases/latest) · [查看全部版本](https://github.com/yuzhouosfw-web/yuzhou-writing-os-releases/releases)

检查与下载需要能够连接 GitHub，使用更新入口不需要 GitHub 账号。当前使用语宙自身的更新入口，尚未通过 Obsidian 社区插件市场分发。

Release 中的 `yuzhou-update.json` 与 `yuzhou-update.bin` 由插件更新器配套使用，不是首次安装的完整仓库包；GitHub 自动显示的 `Source code` 压缩包也不能代替完整产品包。
